按下錄音鍵，說完後按停止，網頁會顯示逐字稿、AI 摘要，並提供錄音檔下載。

🔒 本工具不會將你的錄音、逐字稿或摘要儲存到任何伺服器。錄音只存在你瀏覽器的記憶體中，離開或關閉分頁就會消失；產生逐字稿與摘要時，錄音或文字會直接從你的瀏覽器送到 Google Gemini API（需要你自行輸入的 API Key，Key 只存在你自己的瀏覽器 localStorage，不會上傳到任何其他地方）。
⚠️ 你的瀏覽器不支援錄音功能所需的部分技術（建議使用電腦版 Chrome 或 Edge）。
設定（Gemini API Key／語音辨識語言）

設定只會存在你目前使用的瀏覽器（localStorage），換裝置或清除瀏覽器資料需要重新輸入。若這個網頁之後給其他人使用，每個人都需要輸入自己的 API Key。
